개인정보처리방침

Secret Guard for AI Chat · 개발자 김의엽 · 시행일 2026-10-01

Secret Guard는 어떤 개인정보나 사용자 데이터도 수집, 저장, 전송하지 않습니다.

1. 처리하는 데이터

확장 프로그램은 지원하는 AI 채팅 사이트에서 사용자가 붙여넣거나 입력하거나 첨부하는 텍스트를 사용자의 브라우저 안에서만 검사합니다. 검사는 확장에 포함된 정규식 규칙으로 이뤄지며, 검사한 내용은 메모리에서 즉시 사라집니다.

2. 수집·저장·전송

  • 어떤 데이터도 서버나 제3자에게 전송하지 않습니다. 확장에는 네트워크 요청 코드가 없습니다.
  • 입력 내용, 탐지 결과, 방문 기록을 저장하지 않습니다.
  • 분석 도구, 광고, 추적 코드를 사용하지 않습니다.
  • 계정이나 로그인이 필요 없습니다.

3. 권한 사용

지원하는 AI 채팅 사이트에서만 동작하도록 해당 사이트에 대한 접근 권한만 사용합니다. 이는 입력 내용을 로컬에서 검사하기 위한 목적으로만 쓰입니다.

4. 소스 코드

전체 소스 코드는 공개되어 있어 누구나 위 내용을 확인할 수 있습니다: github.com/kimeuiyeob/secret-guard-release

Privacy Policy

Secret Guard for AI Chat · Developer Kim Eui Yeob · Effective 2026-10-01

Secret Guard does not collect, store, or transmit any personal information or user data.

1. Data handled

On supported AI chat sites, the extension checks text you paste, type, or attach entirely inside your browser using regular-expression rules bundled with the extension. Checked content is discarded from memory immediately.

2. Collection, storage, transmission

  • No data is sent to any server or third party. The extension contains no network request code.
  • Input content, detection results, and browsing history are never stored.
  • No analytics, advertising, or tracking of any kind.
  • No account or sign-in is required.

3. Permissions

The extension only requests access to the supported AI chat sites, solely to check input locally.

4. Source code

The full source code is public so anyone can verify this policy: github.com/kimeuiyeob/secret-guard-release
